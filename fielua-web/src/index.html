開発者の初期設定

iPhone の Fielua がなくても、ここで開発者として登録できます。

管理キーをまだ作っていないとき

下のボタンで作ったキーを、Cloudflare の Worker の「設定 › 変数とシークレット」に、シークレット ADMIN_TOKEN として貼り付けて保存してください。キーはこの画面にだけ出て、どこにも送りません。

管理キーは登録に一度使うだけで、この端末には残しません。
